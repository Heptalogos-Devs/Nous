# Nous 源码索引

按要修改的能力查找负责者，再沿实际调用链阅读。产品边界和当前进度见[架构](../../docs/ARCHITECTURE.md)与[当前工作](../../docs/CURRENT.md)；各专题合同位于 [docs/design](../../docs/design/)。

| 要处理的能力 | 位置与职责 |
|---|---|
| 可读标识符 | [common/identifier.py](common/identifier.py)：65 位括号式标识符生成、类型识别、修订号解析与事务内唯一分配；[common/_identifier_words.py](common/_identifier_words.py)：固定单元表。 |
| 实例启停与装配 | [runtime/bootstrap.py](runtime/bootstrap.py)：`initialize_instance`、`open_instance`、`Runtime.cognition` 和任务目录装配；同一运行期复用共享资源并提供绑定 Namespace 的实际操作。 |
| 实例身份、路径和占有 | [runtime/instance.py](runtime/instance.py)：`InstanceLocator` / `InstanceProfiles`（可读名称注册与当前选择）、`InstanceLock`、`inspect_instance`；[runtime/paths.py](runtime/paths.py)：`ResolvedPaths`；[runtime/bindings.py](runtime/bindings.py)：持久资源身份与位置核对。 |
| 配置定义与来源 | [configuration/definitions.py](configuration/definitions.py)：`NousConfig` 和基础字段；[configuration/metadata.py](configuration/metadata.py)：`ConfigModel`、不可变容器及 `setting`；[configuration/service.py](configuration/service.py)：来源合并、一次校验的 `ConfigSnapshot.values`、字段目录与原子文件保存。模型、媒体、内容和认知配置分别位于 [models/configuration.py](models/configuration.py)、[media/configuration.py](media/configuration.py)、[content/configuration.py](content/configuration.py)、[cognition/configuration.py](cognition/configuration.py)。 |
| 配置变更与生效 | [application/configuration.py](application/configuration.py)：`ConfigurationOperations`、`open_configuration_operations`，在共同执行边界处理在线/离线变更、路径与数据绑定、即时应用及待重启状态。 |
| 操作、期限与关闭 | [runtime/execution.py](runtime/execution.py)：`ExecutionManager`、`OperationContext`，管理嵌套操作快照、Runtime 观测作用域、并发名额、期限、阻塞任务与实际完成后的关闭。 |
| 数据库和事务 | [storage/database.py](storage/database.py)：`Database`、`ReadTx`、`WriteTx`、SQLite 连接策略和基础表；写事务在读取依据前取得写锁，同一文件提供 DBOS 同步引擎；各领域表由对应模块提供 metadata。 |

| CAS 字节及内容引用 | [storage/content.py](storage/content.py)：`ContentStore` 的流式准备、发布、读取与事务内引用；[storage/content_types.py](storage/content_types.py)：`BlobRef`。 |
| 原件、结果及来源 | [content/contracts.py](content/contracts.py)：共同引用、选区、实际表示及来源值；[content/artifacts.py](content/artifacts.py)：`ArtifactStore`（normalize_selections/read_selections/text_views、get_many/get_many_in、read_view_many 与多媒体 ContentReadView） 接纳、范围读取与本地借用；[content/results.py](content/results.py)：`ResultStore` 原子采用、producer_key 唯一采用与冲突、结果视图；[content/mappings.py](content/mappings.py)：已采用表示的显式坐标映射与精确原文回读；[content/provenance.py](content/provenance.py)：只遍历相关祖先的血缘与支持根查询；[content/schema.py](content/schema.py)：规范化输入组、parts、origins 与输出关系。 |
| Markdown 正文与准备 | [content/text.py](content/text.py)：`TextView` 的完整原文、精确范围、无损/完整块分片与按需块绑定；[content/edits.py](content/edits.py)：固定正文上的 UTF-8 精确变更；[content/citations.py](content/citations.py)：共同 source 链接解析与生成链接目标整理；[application/preparation.py](application/preparation.py)、[content/text_cache.py](content/text_cache.py)：批量准备及纯结构缓存；[content/projections.py](content/projections.py)：批量复用或采用保留原选区的语义文本。 |
| 模型连接与凭据 | [network/__init__.py](network/__init__.py)：`ModelConnections` 管理协议客户端和网络资源；[credentials/__init__.py](credentials/__init__.py)：`Credentials` 解析 env/file 引用。 |
| 模型请求及任务 | [models/configuration.py](models/configuration.py)：模型、任务配置与共同路线解析；[models/input.py](models/input.py)：显式 slot_key、同槽离散片段、joint/逐批语义组与按选中路线重规划；[models/tasks.py](models/tasks.py)：静态 TaskCatalog、任务自己的输入准备、来源键校验与有名产物；[content/annotations.py](content/annotations.py)：概念出现/路径提案、正文绑定与公开标注读取；[models/executor.py](models/executor.py)：当前请求、切换时调用准备回调及流；[models/policy.py](models/policy.py)：请求尝试、路线缺项、错误分类与期限；[models/operations.py](models/operations.py)：共同 prepare_group/produce、原生视频路线选择、按需转写、preview/probe 与独立结果采用；[models/computation.py](models/computation.py)：FrozenLanguageTask/PublishedComputation 的正式内容引用与冻结/恢复序列化；[models/protocol.py](models/protocol.py)：沿 SDK 补充 video_url 内容编码。 |
| Prompt | [models/prompts.py](models/prompts.py)：`PromptCatalog`（describe/diff/restore 与编辑上下文）、`PromptContext`、`PromptCompiler` 及来源用途与实际范围的消息说明；[models/resources](models/resources/)：包内模板与 manifest，实例可覆盖。 |
