# Journal 输入示例

两个 Note 和一篇人工修订文稿可用于正常使用通路。短引用由实际命令返回；不要把示例名当成已存在的对象。

- `experience-a.md`：取消等待与后台工作。
- `experience-b.md`：调查和修正。
- `manual-journal.md`：手工文稿，引用 S1/S2 时需同时提交实际 source binding。
- `annotation-proposal.json`：局部概念提案形状；B1/B2 必须来自实际 TextView，采用者按实际块调整。

这些是内容示例，不是 Fixture 框架或质量基准。运行产物保存在项目 temp。
