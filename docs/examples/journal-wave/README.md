# Journal 接入样例

`cancellation.md` 与 `transaction.md` 是两份原始材料；`reflection.md` 是同时使用它们的解释性文稿。`annotation.json` 展示 reflection 的局部概念和路径；实际命令应使用系统返回的正文 Artifact 及标注结果。

样例不代表真实世界观测。导入时明确作为操作者提供的研究材料，不伪装为主体曾经历的事件。新解释保留 A/B 的共同依据，复制 reflection 不增加原始来源数量。

写作和标注使用正式包资源 [journal-draft](../../../src/nous/models/resources/journal-draft/prompt.toml) 与 [annotate-concepts](../../../src/nous/models/resources/annotate-concepts/prompt.toml)。使用方法见 [实验通路](../../development/journal-wave-experiments.md)。
