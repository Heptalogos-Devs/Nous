# 当前目标架构

## 基础平台与认知产品分离

本仓进入 Bun + TypeScript + Rust 重建阶段。第一交付物是可独立安装、独立发布、独立服务其他软件的基础平台。完整基础设计见 [基础平台](design/FOUNDATION.md)。

职责方向：独立安装与运行环境提供资源；配置、诊断、存储和 CAS 各自完整拥有机制；内容提供读取及来源；模型与 Prompt 提供能力明确的任务；应用层把这些组成可直接使用的 SDK/CLI 操作。HTTP、MCP、gRPC 适配同一业务能力。

基础平台不导入 Nous 认知概念、旧 Python 类型或 VCP 运行时。之后的 Nous 作为独立消费者逐步接入，正式认知语义仍参考 [领域词汇](../GLOSSARY.md)、[历史产品设计](references/README.md)与原始设计讨论。

旧 Python/PyO3 运行代码已整体归档。当前基础平台尚待实现，禁止将历史文档所描述的功能报告为新仓现有能力。
