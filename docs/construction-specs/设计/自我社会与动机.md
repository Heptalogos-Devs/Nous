# 自我、社会认知与动机

## 共同运行方式

Self、Social 和 Motivation 是 knowledge 中独立的语义模块。它们共用修订、来源、时间和权限机制，参与同一次相关成长。主体只启用其中一部分时，认知运行时按已供给能力准备内容。

这些模块返回主体当前的认识。世界事实与账号资料由其原所有者提供；行动、承诺和任务由 Hept 决定。读取结果按当前活动、目的与受众选择，避免每次发送一份完整人格档案。

## Self 的可独立修订事项

SelfAspect 保存 `kind, content, context, stability, confidence, sourceRefs, relatedRefs`。kind 覆盖身份、角色、偏好、价值、表达习惯、能力、知识领域、局限和阶段性自我理解。不同事项单独修订，长期价值和当前心境分别表达。

当前心境与疲劳由 Hept 的生活状态提供，进入当前情境；持续偏好与稳定自我认识在实际经历和反思中逐步形成。成长工作记录支持改变的经历、旧认识与新解释。

`persona.read` 返回当前适用的 facets 和叙事；`knowledge.revise` 完成明确的 Self 编辑；`growth.run` 的 narrative 用途根据所选经历与已有修订形成阶段叙述。管理员编辑保留 operator_edit 来源，主体自然变化保留相应经历。

## 个体知识与模型能力

DomainKnowledge 表达某个领域的熟悉程度、学过的内容、可以解释或应用的部分、近期学习证据和仍然困惑之处。读取时给出自然语言的知识立场，而非对每道题建立资格记录。

角色合同按已学会、看过但未理解、当场推断、不熟悉组织当前表现。主观模型可以推断、查资料或请专业 worker；向听众描述时保留实际过程，例如“我刚查到”“我试着推一下”。worker 的完整专业能力属于该次工作，主体查看并学习后形成自己的认识。

学习过程保存想了解的问题、实际读过的资料、主体自己的解释或实践结果、当前理解和下一项困惑。Hept 的长期学习 Pursuit 可以跨多次会话；Nous 每次按真实接触补充知识与学习偏好。练习和应用是正常学习活动，由任务需要决定。

## 多文件种子与当前人格

种子导入接受文本、Markdown、图像和目录包。文件名和目录自由，入口清单只列材料、创作说明与选择的世界起点。原始文件及版本保留。

`seeds.preview` 完成原件接纳和内容解释，返回按 Self、Memory、Social、Motivation 分组的 proposedChanges，以及与当前认识的关系。预览是可编辑的业务成果，支持选择其中内容。`seeds.apply` 采用所选组，并记录 initial_setting 来源；虚构早期记忆保留设定时间与本次采用时间。权限内容由管理设置单独处理。

重新导入种子时，对明确相同的 facet 使用原身份并给出新修订；新增事项新建。已有自然成长与新设定出现冲突时，在预览中呈现具体事项，由管理员选择保留、替换或并存。

界面同时展示原始种子、当前 Self、自然成长来源和本次模型使用的人格片段。可导出可读的 soul Markdown；再次编辑该文件通过同一预览与采用操作进入正式认知。

## 具体人物与群体认识

Social 以 Person、Group、Community 和 AccountRef 连接认识。PersonUnderstanding 保存主体关于某人的自述资料、兴趣、习惯、角色、身份线索与不确定判断。Account 的平台事实由 Directory 提供，Social 保存主体实际得知的内容和解释。

RelationUnderstanding 包含 `fromRef, toRef, dimension, degree, domain?, context?, confidence, valid, sourceRefs`。关系有方向；degree 描述亲近、熟悉、冲突等程度，confidence 描述对这一认识的把握。技术信任可以限于某领域，亲密与专业信任分别变化。

群体认识保存成员关系、角色、共同经历和交往习惯。主体观察到其他两个人之间的关系时，from/to 使用那两人的引用，而非强制一端为主体。

上下文准备内部的 `social.readContext` 根据说话者、参与者、会话与目的取得人物概况、当前相关关系和语言惯例。主体审议可以取得适用私密认识；renderer 取得当前听众允许使用的表达资料。

## 语言惯例

LanguageConvention 保存形式、含义、语用方式、适用人物/双方/群体/频道/社区、例句、来源、确定程度和修订。

理解时先取与当前作用域匹配的解释，再取已被明确推广到更广作用域的解释。相同词在两个群中的不同含义并存。显式解释是强线索，反复正确使用与后续纠正可以改变当前认识；一次猜测保存为局部 uncertain 项。

表达时选择听众熟悉的词义、称呼与表情。听众跨圈时，可以解释或换用通用说法。对语言风格的学习从真实交往取得，MaiBot 的局部提示组织和自然表达方法用于实现，原始群体用语保留其来源。

## Motivation

MotivationItem 保存 desire、concern 或 evaluable_expectation，包含自然语言内容、相关对象、重要性、有效范围、来源与可选 criterion。项目允许多个愿望并存或相互冲突。

Criterion 包含 `mode: achieve/terminate/maintain/avoid`、作用区间、适用情境、谓词或语义条件、所需观察覆盖、相关来源。明确时间与计数条件使用类型化谓词，谓词只读获准的事实；含义复杂的条件由相关模型评价，并保留所用事实。

| 模式 | 评价规则 |
|---|---|
| achieve | 区间内出现满足条件的事实则 satisfied；区间结束且覆盖充分仍未出现则 violated；其余 unknown |
| terminate | 目标状态结束且有结束依据则 satisfied；到期限仍持续且覆盖充分则 violated |
| maintain | 区间内有破坏事实则 violated；区间结束且覆盖充分、条件持续成立则 satisfied；进行中给 unknown 与进展 |
| avoid | 禁止事件出现则 violated；区间结束且覆盖充分、未出现则 satisfied；观察不充分时 unknown |

返回 `verdict, applicable, observationCoverage, basisRefs, evaluatedAt, criterionRevision`。评价不能从“没有收集到消息”推断“事件没有发生”；覆盖信息由世界/工具/交往来源提供。条件发生变化后基于新修订重新评价。

## 认知与行动的交接

认知准备内部的 `motivation.consider` 返回与当前情境相关的愿望、关切、期望评价和建议再次考虑的时间。这些内容随正式 ContextView 供 Hept 使用。Hept 可以选择形成 Pursuit、调整安排、作出承诺或继续观望，采用结果回传为实际行动来源。

一个愿望是否变得不重要，在 Nous 中形成认识修订；已经对别人承担的责任由 Hept Commitment 继续表达。追求完成可以成为愿望评价依据，但取消任务本身只说明停止了行动。

## 自然成长的强度

成长输入包含旧认识、实际新经历及相关反例。稳定事项的重大改变需要模型明确给出变化依据和关系；一次短暂情绪主要影响当前状态。这里使用同一组修订与形成规则，没有独立人格审批流程。

输出是少量具体变化及来源，适合对当前相关事项修订。保留没有形成变化的结果，避免为每轮交往强行生成新偏好或新人格特征。
