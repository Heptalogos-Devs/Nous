## 需要修正的现有实现

### Episode 自动草稿推进参数数量不一致

- `crates/runtime/src/segmentation.rs` 的草稿更新语句 `UPDATE episode_drafts ... WHERE draft_id=$1` 只使用 `$1..$4`，该路径连续执行五个 `.bind`，多绑定了 `domain`。默认分支与 Nous 开发分支均存在。
- **受影响的运行路径**：带 Session 的 Observation → ExperienceItem → segment_experience → 写入草稿成员后更新草稿 → SQL 参数错误导致本事务回滚 → 分段 cursor 保留之前的提交值。真实调用时会在存在待处理 Experience 的普通推进分支命中。
- 代码：[默认分支第 112–113 行](https://github.com/Heptalogos-Devs/Nous-Wave/blob/412b062082afb75ccfae4c3f69fc606d3e3cc862/crates/runtime/src/segmentation.rs#L110-L113)。

### 真实接触被提前登记

- Nous 的 `packages/openclaw/src/index.ts` 在 `prepareModelInput` 的前半段调用 `recordObservation` 写入选中的 contacts，随后执行媒体准备、输入预算计算、Projection、最终模型输入检查和 Host `admitted`。
- `crates/material/src/service/observation.rs` 在同一提交路径接着写入 Runtime ExperienceItem；后续准备失败后，这些接触仍会成为持久经验和维护输入。

- 代码：[原生输入第 701–985 行](https://github.com/Heptalogos-Devs/Nous-Wave/blob/aa93ede671177f129799643227ddb601c5b2e829/packages/openclaw/src/index.ts#L701-L985)、[Observation 第 32–311 行](https://github.com/Heptalogos-Devs/Nous-Wave/blob/412b062082afb75ccfae4c3f69fc606d3e3cc862/crates/material/src/service/observation.rs#L32-L311)。

## 仍缺完整产品路径

**独立主体连续性**：多文件人格/图片种子包、独立 PersonProfile、跨账号人物对应、主体包导入导出及两库共同恢复。现有 Subject、Seed、Self、Social、Material 和备份底座提供组成能力。

**自然成长与个体选择**：多域反思可以提交正式认知，但 Social 自动成长仍依赖实际交往来源接线。Attention 当前排序基于级别、相关性和来源公平，人物关系、动机、精力、中断代价尚缺完整的统一选择模型。

**完整世界生活**：WorldLife 与 Calendar 有正式实现；长期心境、物品与场景交互、分层 NPC 能动性、自然生活节奏和可核实的跨日连续场景仍待建设。

**执行与交付**：原生 OpenClaw 提供专业执行与工具调用；Subject 专属可查看、可接管的浏览器/桌面环境和跨计算环境搬运仍缺完整产品入口。QQ 的 GIF 原始回复与浏览器结果交付属于当前 Draft 未完成的真实场景。

**管理与可观察性**：CLI/API、受保护安装和 operator 草案已存在，图形产品、远程跨设备管理、存储与费用账本、告警、统一配置入口尚未完整交付。
