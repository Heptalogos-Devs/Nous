## 图谱语义

- 调用边（`call`）表示明确的同步/异步调用或服务请求；数据边（`data`）表示材料、候选或计算结果的传递。
- 持久写入边（`write`）表示所属 Authority、事件或状态被提交；读取边（`read`）表示请求方取用已有数据。
- 事件边（`event`）表示消息、通知或调度触发；生命周期边（`transition`）表示单一对象的实际状态改变。
- 引用边（`reference`）只表达稳定引用，不表达数据复制或所有权转移；需求边（`requirement`）标明现有能力与未完成目标的关系。

**方向始终是来源/调用方 → 接收方/被引用方。** 图中对象颜色表达所属系统，双边框表达持久语义单元。细节和每条边的代码来源均列在同名说明文件中。图上有相同节点名称时，仍依据节点 ID 和明确的边标签区分调用。
