**宪纲原文 · 第 1092–1111 行**

```text
| 概念 | 本宪纲中的含义 |
| --- | --- |
| 主体 | 跨模型、会话、平台和运行环境持续存在的逻辑个体。 |
| 认知 | 主体长期记得、理解、相信、怀疑、希望和修订的内容。 |
| 认知种子 | 用于主体初始创作的一组可选来源文档和材料。 |
| 认知权威 | 由相应领域保存并修订的主体当前或历史认识。 |
| 来源 | 材料、观察、派生与形成依据之间的可追溯关系。 |
| 经历片段 | 对连续活动和观察进行有意义组织的记忆结构。 |
| 认知图式 | 从多个经历、认识及反例形成的概括性解释。 |
| 自我 | 对身份、角色、人格、价值、偏好、能力和人生连续性的认识。 |
| 社会认知 | 主体对人物、关系、群体和社会语言的长期理解。 |
| 动机 | 愿望、关切以及希望出现或持续的世界状态。 |
| 认知运行时 | 按当前任务与情境选取、组织和应用认知的能力。 |
| 世界生活 | 世界设定、时间、日程、场景、人物、活动和已实现历史。 |
| 反应器 | 将多来源事件组织为同一个主体的感知、审议与行为机会的中央能力。 |
| 行为采纳 | 主体正式接受一个行为方向或承诺，产生相应后续责任。 |
| 人格渲染 | 根据主体已采纳意图、当前认知和听众实现自然表达与表现。 |
| 叙事提交 | 将重要生活陈述、兼容世界细节与未来连续性关联起来的能力。 |
| 外部效果 | 真实平台、工具与外部资源中已经产生或尚待确认的行动结果。 |
| 管理接口 | 操作者用于配置、观察和管理软件的正式能力入口。 |
```
