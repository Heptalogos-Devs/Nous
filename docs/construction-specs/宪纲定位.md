当前交付包含全部基础认知领域、自然形成与检索、生活世界与基础人物、全局注意和自发选择、专业任务、完整媒体消息与自然表达、角色/权限/配置/预算、CLI/API/Web 管理、跨平台安装、未来导出恢复与物理清除。普通语音和视频附件属于正式消息与材料能力。

实时连续语音/视频通过渠道输入与材料时间段扩展；三维/VR 通过 world 的 Percept 与 Action 连接呈现；深度 NPC 使用独立 SubjectId 和自己的认知/行为实例；共享世界扩展已有参与者与局部视角权限；更强的检索策略在 Query/Result 边界替换；桌面壳复用完整 Web Console 与 Client。当前不建立这些方向的空服务和预先运行的后台任务。

原文中的历史项目、研究产品与学术材料保持其参考性质。本包的算法参数是可配置工程起点，软件的主体连续性与独立运行按正式业务操作实现。
