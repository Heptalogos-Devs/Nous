# Nous Wave × Heptalogos 完整施工方案

本包依据项目宪纲，从空数据与新代码结构重建两个产品。Nous 提供独立认知能力，Hept 提供独立生活与行动能力；同一主体通过正式接口协作。旧源码可用于查阅和选取独立实现，当前实现按新责任结构建立。

## 已确定的架构

两个模块化 TypeScript 服务、两个产品数据库、一套共同值类型，各模块封装自己的状态和事务。Node 24 LTS、TS 7、PostgreSQL 18、Kysely、DBOS 5.3、AI SDK 7 与官方 DBOS AI 集成构成主干。LanceDB 负责可重建的中文全文及向量检索。

Hept 主观审议和表达直接使用 AI SDK。OpenClaw 负责专业任务与计算环境，并提供独立 Nous 深度认知集成；逐调用接口在其原生责任位置改编。AstrBot 负责默认渠道，QQ 使用其 OneBot 适配器和 NapCat；实际发送 owner 保留物理回执。MaiBot 的独立自然交往资料与方法按需直接改编。

主体生活包括完整世界与日历、感知通道、精力、活动中断、自发机会、持续追求、承诺和交往。认知包含来源、五种时间、历史认识、记忆、经历、日记、图式、概念、Self、Social、Motivation、NousQL、成长与后台维护。

## 当前范围

本次完成全部正式核心能力及独立/联合 API、Client、CLI、Web Console。Windows、Ubuntu 与 macOS 采用同一领域实现，服务与凭据由成熟平台工具承担。配置、身份、来源时间、操作状态、费用和 trace 从首条本地交往链进入实际代码。

第四十九章的实时连续视音频、三维/VR、深度独立 NPC 与共同世界作为后续扩展。普通媒体、基础持续人物、后台工具、当前 Web 管理已经包含在本次范围内。

没有旧数据迁移或兼容任务。未来正常产品的主体导出、跨机迁移、分支、备份恢复和清除属于正式能力，使用本轮创建的资料实施。
