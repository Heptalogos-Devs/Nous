# 活动、追求、任务与计算环境

## 活动作为完整工作对象

Activity 保存主体正在开展的一件事：目的、来源、当前状态、采用的决定、允许使用的能力、成果、等待条件和继续点。活动可以跨多个 Reaction、模型调用和 Session。

状态为 proposed、active、waiting、paused、completed、cancelled。waiting 说明在等待具体事件；paused 说明当前不推进；completed 需要业务所需成果或明确结束决定。运行失败记录在对应 TaskRun，活动可以带着已有成果继续。

公开操作 `activities.start/read/list/updateProgress/wait/resume/pause/cancel/finish` 返回完整 ActivityView。对象内部的任务分配和执行记录由 Activity 系统读取，调用者不用查询三张表后判断是否完成。

## Pursuit 与条件

Pursuit 是主体采用的一项持续追求，引用 Nous 的精确 DesiredConditionRevision，保存采用原因、当前计划、相关活动、最近评价和再考虑条件。它与一次任务分别存在：搜索一次资料可以完成，学习一门知识的追求仍然继续。

`pursuits.adopt` 读取实际条件和当前权限，建立追求及首个 Activity。`pursuits.reconsider` 在条件修订、目标冲突或新结果出现时作出继续、调整、暂停或结束决定。条件的评价由 Nous `motivation.evaluate` 完成，Heptalogos 保存其评价引用和当前行为后果。

新条件不会悄悄替换已采用的目标。收到条件修订通知后，相关 Pursuit 进入待再考虑，阻止基于旧目的的新 consequential 操作；已发生的效果和可继续读取的成果保留。

计划是人类和模型可理解的目标、步骤与条件，可以直接修订。程序只解释明确的任务依赖、等待事件与结束条件；自然语言计划不编译为通用 DSL。

## 委派与成果交付

主观决定中的 delegation 包含目标、材料引用、允许工具、时间/费用范围和所需成果形式。Task 保存这一采用合同，OpenClaw 保存原生执行 Session、工具循环与子代理。

流程为：采用 Task → 启动一个原生 run → 工具执行 → 保存 TaskResult → 通知主体 → 明确读取 → 后续决定。子代理完成时不直接替主体发言或修改人格。

TaskResult 包含摘要、成果文件、可阅读材料、来源、执行问题、实际费用和完整原生运行引用。专业报告可以同时提供短介绍和可按需打开的详情。主体实际读取的部分进入自己的经历；后台日志仍供管理员排查。

跨活动查看结果通过 `tasks.readResult` 授权并提供完整结果。旧实现中必须把结果重新挂回当前 Activity 才能读取的流转删除；只要目的和来源许可允许，结果可以被多个活动引用。

## 等待、取消与继续

等待条件可以是 taskResult、message、worldPoint、conditionChanged 或 operatorResume，条件由各事件 owner 投递通知。一个活动只有当前需要的下一等待条件集合；不另建并行恢复流程树。

恢复先读取原 Task/Run 和已经保存的成果。明确尚未开始的任务可以启动；正在运行的继续等待或取消；已经完成的直接消费成果；状态未知的保留原身份并通过原生状态接口核实。

取消活动不抹掉已经发生的效果，也不删除已付费成果。能停止的原生工作调用取消接口，留下实际终态。后续再开始属于新的明确业务意图。

## 主体的工作空间

每个主体拥有独立工作目录、成果目录和浏览器配置。Device 子系统提供环境创建、状态、资源挂载、截图/视图和人工接管入口；通用 shell、文件、浏览器和桌面操作由 OpenClaw 及成熟工具提供。

默认专业 worker 在容器或既有沙箱执行。浏览器使用 OpenClaw 的 Playwright/CDP 能力，桌面访问通过选定的远程桌面或计算机操作 provider。项目不开发自己的浏览器引擎、终端模拟器、容器运行时和屏幕传输协议。

操作授权按 workspace、域名/网络、工具和外部账号范围提供。默认 worker 只读输入材料，可写本任务成果目录；需要真实外部写入时，通过已采用的行为许可开放相应操作。普通命令行执行不能继承机器维护助手的权限。

## 环境与世界设备

世界里的手机、电脑、书本和真实执行环境可以有关联。世界设备提供可供性与叙事，真实浏览器/文件提供执行和资料来源。一个“看视频”动作可以委派搜索和下载，主体之后读取视频内容，世界记录自己的设备使用经历。

真实运行耗时、下载进度和世界动作时长分别保存。worker 在数秒内完成搜索时，世界可以继续走自己的时间；已采用的世界行为根据实际时间进展实现。

## 人工查看与接管

管理界面可以打开当前浏览器或远程桌面、查看任务文件、暂停自动工具操作并接管。接管是明确的环境状态：automatic、operator、paused。进入 operator 后停止新的自动输入，已进行的网络请求和工具结果仍正常返回。

退出接管时保存一段实际操作说明与相关成果，主体下一次读取能够知道环境发生了变化。凭据保存在相应环境的私有配置；截图和导出文件遵循本机个人数据权限。

无桌面的安装仍提供浏览器、文件、shell 与任务管理。图形接管作为同一环境的可选呈现，关闭界面不结束后台活动。

## 共同成果接口

文件、网页快照、生成媒体和结构化数据统一使用 `ArtifactResult` 引用，实际字节由材料/工作空间存储所有者负责。下载接口返回流，预览接口返回受限表示；内部临时路径不进入模型或跨产品 API。

附件移入长期认知时，通过 Nous 材料导入操作取得稳定引用。临时文件清理只针对没有保留用途的任务目录；已提交成果和被认知引用的材料依其生命周期保留。
