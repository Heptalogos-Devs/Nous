# 管理、命令行与界面

## 统一的产品入口

Heptalogos Console 组合主体、生活、通信、任务、认知与设置。Nous Console 可独立运行，认知页面以可复用组件包供联合 Console 使用。两个界面访问各自公开 API，联合入口不复制领域逻辑。

技术选用 React、Vite、TanStack Query、React Aria Components、FullCalendar Standard 和 CodeMirror。图谱读取使用 Graphology 与成熟图形渲染库。组件、焦点、键盘交互、日期网格和编辑器交给现成库，项目实现具体的信息组织与交互。

## 日常使用界面

首页展示主体当前状态、最近重要变化、当前活动和直接对话。详细任务、日历、认识与管理按实际操作逐渐展开。日历区分计划、已经生活和主体已知；任务区分原目标、已取得成果、下一动作和受阻条件。

界面采用主体状态球、按事件出现的动态岛、底部功能入口与独立管理助手。状态图形只表达已读取的运行信息；后台故障在相关操作位置说明。视觉使用稳定语义色与原生组件交互，不把所有技术指标放在首页。

Subject Chat 与管理助手分别进入不同会话。前者向主体发出行为意图；后者在授权后调用配置、安装和运行管理。登录与启动主体是两个操作，未启动主体仍可管理系统。

## 创建、设置与资料编辑

创建向导按名称/能力、可选种子、可选世界、模型与预算、启动选择推进。只有选择对应功能时才展开有关字段。已有主体不会因重新打开向导而重置种子、时间或精力。

种子编辑使用真实多文件树，支持原文、草稿和当前采用结果。资料与人格页按事项显示来源及修订，提供预览、采用、撤回和比较。完整世界管理同时显示作者视角与主体视角，切换时明确当前视图。

配置页从 owner 提供的 descriptor 构建，默认展示 Standard，Advanced/Developer 按需展开。密钥输入单独提交；已保存的秘密不回显。跨模块配置使用同一操作反馈结构，显示已生效或需要重启的实际状态。

## 正式 API 与 CLI

Fastify 提供公开 JSON API 和必要文件流，Zod 为公开对象与操作 schema 的来源，OpenAPI 与官方 Client 从其生成。CLI 用 Commander 和 Clack 组织命令、参数与交互。普通查询输出自然可读文本，`--json` 返回正式结构。

| 操作场景 | CLI 入口 | 完整业务操作 |
|---|---|---|
| 创建与绑定 | subject create/bind | 主体创建、能力、可选种子/世界 |
| 阅读与查询 | memory list/read、recall | 完整认知与 NousQL |
| 初始化资料 | seed edit/preview/adopt | 草稿、提案与采用 |
| 世界与日历 | world read/advance、calendar | 当前场景、计划、历史与例外 |
| 活动与任务 | activity start/status/resume、task result | 实际目标、状态与成果 |
| 人物与消息 | person read/link、conversation read | 资料、身份与真实消息 |
| 运行管理 | start/pause/stop/status | 产品、主体和后台分别控制 |
| 配置与成本 | config get/set、usage | 有效配置、来源、实际用量 |
| 可移植性 | subject export/import/fork、backup/restore | 对应的完整数据操作 |

人类命令自动取得当前选定主体与普通对象最新修订；需要确认的覆盖修改先显示 diff，再提交原读取版本。Agent/API 调用可显式提供 expectedRevision。用户无需手填 transactionId、focusRevision、nativeRunId 或内部授权令牌。

CLI、Web 和 MCP 统一调用完整操作。MCP 普通主体工具默认只提供认知查询、实际阅读和已授权动作；管理 MCP 使用不同的认证身份和工具集合，不能由聊天参数临时变成管理员。

## 身份与认证

使用 Better Auth 的 session 和认证实现，Fastify 只做正式挂载与业务权限检查。首次认领使用本机一次性设置入口；随后按管理员会话访问管理操作。远程访问使用 HTTPS 与明确的安装访问配置。

Service identity 用于两个产品和原生执行器互访，仅授予其业务角色。用户登录、服务身份、主体行为身份和机器维护身份分别存在，前端不代替服务决定权限。

管理操作可由 System Assistant 使用同一 API 提议或执行，按操作后果请求必要确认。机器维护助手采用独立 OpenClaw 实例和机器凭据，在产品停机时仍能启动、诊断或恢复服务。其运行资料和对话不进入主体人格。

## 运维视图与人工接管

运维页面按症状提供当前依赖、受影响功能、最近错误、空间和费用。原生 OpenClaw 的技术管理页面可以作为链接打开，产品保留当前主体与任务上下文，不复制原生所有设置。

浏览器/桌面接管、素材查看、任务结果导出与安装恢复都提供实际可执行入口。危险的数据清除和覆盖导入显示具体对象与影响范围，采用一次明确确认。只读状态、翻页和日历移动不反复弹出确认。

## 可访问性与桌面形态

键盘导航、屏幕阅读语义、缩放、长列表虚拟化和错误焦点使用组件库的标准能力。远程浏览器、小屏幕和本机桌面共享页面语义，信息密度随空间调整。

桌面壳采用 Tauri 的窗口/托盘/启动集成，核心服务继续独立运行。关闭窗口只关闭呈现，托盘提供打开界面、查看状态和显式停止服务。三维、VR 或其他世界呈现通过正式 WorldView、Perception 与动作接口接入，不直接读写世界数据库。
