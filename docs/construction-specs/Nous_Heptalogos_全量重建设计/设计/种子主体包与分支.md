# 种子、主体包与分支

## 种子作为可编辑的来源

一个种子包可以包含多份 Markdown、图片和其他初始化材料。文件名由作者选择，目录结构服务于写作；系统通过 manifest 的用途提示或内容解释识别自我、关系、愿望、表达习惯和世界入场资料。

`SeedPackage` 保存 packageId、版本、文件清单、内容引用、作者声明与导入时间。每个文件具有稳定 documentId，具体内容版本独立。`SeedAdoption` 保存主体、所采用的 packageVersion、选择范围、产生的认知引用与采用原因。

三种视图分别提供：种子原文、正在编辑的种子草稿、主体当前认识。管理界面可以并列查看和修改，草稿保存不会自动改写人格；“采用修改”才执行明确的认知变化。

## 预览与采用

`seeds.preview` 读取指定草稿，按当前启用领域生成提案并返回可编辑预览。预览包括每项拟形成的内容、源文档位置和修改已有事项的对应关系；世界入场资料单独列为 Heptalogos 的可选采用项。

`seeds.adopt` 接收预览身份、用户选择与当前目标修订，使用原有提案成果完成领域采用。没有修改的来源和内容不会重新调用模型。用户直接提供结构化领域资料时，跳过语义提取，进入同一采用操作。

Self、Social 和 Motivation 在 Nous 内由一次 seed adoption 事务提交。尚未启用的领域保留来源，后续显式启用时再解释对应部分。世界入场通过 Heptalogos 的 `world.enter` 独立业务操作完成，结果关联同一来源包。种子中写下的设定保留 `initial_setting` 来源性质。

无种子创建的 Subject 保持真实空白起点，可以由经历逐步形成认识。界面提供可选模板和示例包，使用前展示其实际内容及采用范围。

## 主体包格式

主体包采用普通 ZIP 或 tar 归档，包含人类可读 manifest、领域数据的公开 JSON 表示、所引用材料与可选世界部分。每个领域提供自己的 export/import 方法，包级操作调用这些正式接口，不由通用脚本直接扫描全库私有表。

| 分区 | 内容 |
|---|---|
| manifest | 格式版本、来源主体、导出时间、包含领域、所需能力与材料清单 |
| cognition | Memory、Self、Social、Motivation、Episode、Journal、Schema、概念及选定历史 |
| sources | 种子、材料、选区、派生关系与已接触来源 |
| continuity | 可选 WorkContext、未完成事项的语义检查点 |
| world | 可选世界定义、日历、角色、已实现生活与世界时间 |
| attachments | 导出范围中实际引用的文件 |

实际账号密钥、登录令牌、机器路径、管理凭据和平台授权不进入分享用主体包。导出预览显示涉及的私人会话、人物和材料，操作者选择范围；引用被排除的来源以明确的省略说明保留，导入方不能取得原秘密权限。

包中的内容散列用于定位不可变字节和完整性检查。格式版本只说明公开包格式，正常读写不增加每对象版本证明链。

## 导入、恢复与分支

`subjects.import` 有两种明确目的。迁入同一主体使用原 SubjectId，在停止旧安装的对应主体后导入；复制或分享使用新的 SubjectId，建立 ForkRecord。目标已存在相同 Subject 时先返回冲突及可选择的替换/另建操作，普通导入不隐式合并两个长期主体。

分支时，Nous-owned 对象获得新的 objectId 与 revisionId，并按包内映射一次替换内部引用。材料字节可以按内容散列复用；来源记录保留“从哪个主体与修订继承”。外部实体保留 issuer 与身份含义，当前安装需要重新选择可用的账号绑定。

Heptalogos 的世界和生活分支同样取得新的 worldId 和行为对象身份；已发送消息、已经执行的付款或其他物理效果以继承历史显示，发送队列不复制为待执行任务。任务检查点可以导入为暂停状态，操作者确认执行环境与授权后再继续。

完整安装恢复则保留同一安装所需的运行记录，由[部署可移植性与清除](部署可移植性与清除.md)处理。主体分支、主体迁移和安装恢复各有一个面向用户的入口，不让调用者手工修改标识符和表。

## 操作的事务范围

种子草稿写入是材料和 document revision 的短事务。预览是可保留的模型成果。采用是认知领域的一次事务。导入大包先完成文件读取、引用映射和静态检查，再按一个 Subject 的导入批次写入暂不可见数据，最终事务发布该主体；失败删除该批次，不影响其他主体。

发布前的 staging 只用于大包批量载入。普通记忆形成与日常反思不经过这个机制。导入完成后重建搜索索引，精确读取立即可用，普通召回显示索引进度。

## 人类操作流程

创建入口依次展示主体名称与能力、可选种子、可选世界、预算和启动选择。空白主体可以直接创建；有种子时展开预览；选择世界后再展开世界参数。导入包从内容预览开始，依次决定身份、隐私与本机依赖。

CLI 对应 `nous subject create`、`nous seed edit/preview/adopt`、`nous subject export/import/fork`。`heptalogos subject create` 组合调用这些操作及可选 world.enter，最终返回同一主体及两侧的实际创建结果。跨服务失败时按原 operationId 继续未完成的一侧。
