# Nous Wave × Heptalogos 重建设计

以持续主体的完整功能重新组织两个产品。Nous Wave 保存认识、经历与人格；Heptalogos 组织世界、生活、注意、行动与交往。两个代码仓库分别发布模块化服务，共享稳定主体身份，通过完整业务操作协作。

本包是2026年10月20日的重建目标。原宪纲、此前实现调查与本次设计分别保存，现有代码用于恢复语义、实际场景和已有资产。新架构采用统一 TypeScript 领域实现，替换旧私有内核、协议链和重复运行机械。

## 主要决定

| 方面 | 重建方案 |
|---|---|
| 系统结构 | 两个模块化服务，内部按完整能力划分子系统；内部直接调用，跨产品走正式 Client |
| 数据与事务 | 每个产品自己的 PostgreSQL 数据库；完整业务操作拥有事务；Kysely 与 pg-boss 在同一事务提交事实和后续任务 |
| 复用 | OpenClaw 执行与渠道、LanceDB 检索、成熟模型 SDK、媒体解析、认证、日历和备份工具承担通用机制 |
| 认知 | 统一身份、修订、来源和时间结构；Memory、经历、Self、Social、Motivation 保留各自语义；一次共享成长处理相关事项 |
| 主体生活 | Hept 拥有世界时钟、日历、人物与生活状态；单前台 Reactor 配合个体化注意和后台任务 |
| 交往 | 当前材料先可读，实际接受后形成经历；普通自然表达短路径发送；重要世界事实与承诺有明确采用操作 |
| 产品 | 完整 API、CLI、独立及联合 Console、多文件种子、人物资料、主体分支、计算环境和跨平台部署一同纳入施工 |
| 旧实现 | 有效素材、付费成果和历史保全；旧内部接口、双写、补丁和已被替换的支撑工程删除 |
