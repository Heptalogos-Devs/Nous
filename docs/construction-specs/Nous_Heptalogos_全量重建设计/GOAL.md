# Coding Agent Goal

完整读取本包 README、项目宪纲、目标设计与相关图谱，按《完整重建与施工顺序》从目标功能重建 Nous-Wave 和 Heptalogos 两个仓库。先检查实际工作树，保全未提交内容、真实主体资料、付费成果与私密资产。

采用本包决定的两个 TypeScript 模块化服务、领域完整操作、独立数据库与事务中心。落实选定第三方依赖，内部只实现项目特有语义。旧代码用于恢复有价值的行为、素材和算法，按新 owner 重建；删除被替换的接口、转换链、原生补丁、测试支架和流程，不保留兼容、双写或旁路。

先贯通同一主体的收件、阅读、原生接受、认知形成、决定、自然表达与实际回执，再依次完成全部认知、世界、任务、成长及产品能力。每项能力同步完成 API、Client、CLI、必要界面和数据操作。原生 Gateway 发送使用公开接口，未知结果保留原交付状态并停止重发。

依照功能覆盖索引完成既有和缺失需求，设计外现有能力按附加能力记录处理。仅用有信息价值的完整场景与集中算法用例验证。分块修改与写文档，实际失败回到负责模块处理。交付完整功能、清理后的代码与当前状态；重大语义分歧明确指出所在操作和影响，保持其他已定工作继续推进。
