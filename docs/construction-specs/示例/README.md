# 可运行场景的输入资料

这些文件是施工时直接使用的配置和产品输入示例。模型配置中的资源名由使用者绑定实际提供方；秘密从指定环境或凭据存储读取。世界与种子中的人物均为示例设定。

`nous.bootstrap.toml` 与 `hept.bootstrap.toml` 只保存启动必要项，运行角色和预算使用 `runtime-settings.json` 导入正式设置接口。未填写的目录使用平台标准路径，数据库例子连接现成 PostgreSQL；本地引导可选择 embedded-postgres 并生成相应连接。

`校园世界` 是完整世界输入：入口清单、背景、地点、人物、日历、规则与初始状态。包内 key 是局部引用，preview 检查关系，create 分配 UUID 并一次解析全部引用。更新包可以明确引用已存在的 UUID。

`人格种子` 包含跨领域自由文本，preview 给出 Memory、Self、Social、Motivation 的采用结果。早期记忆使用 initial_setting 来源，之后的实际交往另行形成。

`场景输入.json` 给出一条课堂中的群聊通知、图片引用与嵌套转发，图片使用由操作者上传的 MaterialRef 替换 resourceKey。前台示例继续查看内容、调用已配置的资料工具、返回结果并自然表达。素材身份由正常 API 创建，示例代码不直接改数据库。

[角色任务](角色任务.md)给出主观审议、自然表达、世界作者、专业执行、成长与维护的初始文本和输入输出组织。
