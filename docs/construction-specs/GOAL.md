# Coding Agent Goal

依据本包《项目宪纲》和当前设计，从空数据重建 Nous-Wave 与 Heptalogos 两个仓库。先读 README、架构、契约与施工顺序，再按正在实施的完整能力读取相关 Spec。清理旧代码、命令、测试支架与派生文档；旧实现只作参考，适用的独立逻辑进入新 owner，不建立兼容、双写或旁路。

采用 Node 24 LTS、TS 7、PostgreSQL 18、Kysely、DBOS 5.3、AI SDK 7 及官方持久集成、LanceDB。成熟能力直接依赖；需要时拉取上游源码，在真实责任位置改编。重点完成 OpenClaw 逐实际模型调用的认知准备/接受合同，以及 AstrBot 发送 owner 的物理回执保留，复用原生历史、工具、渠道和执行机械。

按施工顺序逐个贯通可运行的纵切面，从本地收件、Nous 召回、主体回复和实际经历开始，完成全部认知、世界、自主性、任务、承诺、交往及产品管理能力。配置、权限、时间来源、费用、操作状态与 trace 随首条链落地，未来迁移、导出、分支和清除按正式接口完成。

模块封装内部状态，完整业务操作负责事务。结构不合适就修改正式结构及全部当前消费者，删除补偿层与重复流转。模型成果和实际外部效果按本包的业务语义处理，执行恢复交给第三方。

始终执行 AntiRLHF 的规划、执行、重构与文档要求。分块实施并同步当前文档，运行少量真实功能轨迹和必要规则用例，复用已有场景。完成的标准是全部已定核心功能能够实际使用、两产品独立与联合运行、代码与接口保持清楚简洁；测试数量和证明性产物不构成目标。
