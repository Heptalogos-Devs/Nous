# 持久工作接入的后续计划

## 当前位置

CAS、Artifact 与 ProcessingResult 的前台操作已经纳入 [模型与媒体计划](model-runtime.md)。本文件只保留其后的持久工作接入，不形成第二条要求重新实现内容存储的施工线。

## 后续目标

在真实存在需要关闭后继续的内容/媒体操作时，单独授权接入 DBOS。复用现有应用操作、正式内容引用、ResultStore 和事务；任务系统只负责通用领取、取消与恢复。

DBOS 与业务表使用同一 SQLite，事务内 enqueue 采用其受支持接口。任务入参只保存可序列化值和正式引用；恢复时由组合根提供实际 owner。

阶段成功的产品结果继续独立保存。恢复读取已提交阶段并决定继续未完成工作，不另建命令回执/第二套任务总表，也不自动重置模型尝试的业务含义。

## 开始时要决定的内容

选择真实的长任务作为首个消费者，明确工作阶段、已完成结果、取消和重复交付语义，然后更新本计划。无此授权时，当前 CLI 前台操作不承诺持久恢复。
