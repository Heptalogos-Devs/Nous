# 内容与持久后台工作的接入位置

当前 CAS、Artifact、ProcessingResult 和事务内采用已实现。本轮 Wave 复用这些能力，按其需要整理 borrow_local、来源与精确向量映射。

DBOS 在首次需要跨进程恢复的真实任务中接入，例如大集合增量构建或后台 journalize。业务事务内入队使用现行事务专题的共同连接合同；任务负责自己的幂等身份和成功结果，DBOS 负责持久执行。

本轮 build/query 只有前台执行与取消语义，不建设队列占位、任务总表、通用恢复回执或隐式后台线程。后续接入 DBOS 时复用本轮的原子构建单元及已有结果，不重新实现 Wave 业务。
