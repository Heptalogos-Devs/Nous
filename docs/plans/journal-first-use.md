# Journal 首条认知使用链

本文件保留首条使用链的目标概览；本轮具体施工合同、依赖和完成条件见 [Journal 交付计划](journal-delivery.md)。

## 前置条件

共同输入、正文块、来源、向量、诊断及 Wave 核心已经收敛。概念路径实验已能说明怎样向 Wave 提供真实正文与结构；不要求所有检索指标都达到某个预设阈值。

## 第一条完整能力

实现 Note 主动记录/读取，journalize 草稿与明确采用，Journal 当前/精确版本读取、修订、反馈，以及 Wave 对正文和局部选区的召回。人类可直接写 Journal，不要求先有 Note。Note 与 Journal 的产品语义分别定义，共享有限的文稿版本保存 owner；具体模块见 [认知接入](../design/cognition/integration.md)，复用现有内容与运行基础。

Journal 表只保存认知身份、正文版本/视角/时间及引用；字节仍归 CAS。概念标注引用稳定正文，索引消费它们而不成为新权威。CLI/SDK 共用完整操作；正式 MCP 工具以后按记忆使用任务设计，不逐方法暴露。

## 接入次序

先完成 create/read/revise 的真实手工操作，再让 journalize 模型草稿进入同一个采用入口；然后发布检索快照，读回确切正文与来源。最后接 feedback 的评价和明确更正。

可选维护由当前 Runtime 等待或作为普通后台任务执行；重开实例后按需要发起新的完整操作。

## 使用者得到的结果

能够记下一段经历，把有关碎片整理成一篇 Journal；以后用自然语言找回，看到原文和概念关系；纠正某段认识后，当前查询看到新的适用版本，历史引用仍能回读当时内容。完整多轴知情查询按 temporal-views 分步接入，不提前声称已支持全部 $asof。
