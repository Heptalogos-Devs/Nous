# 模型与媒体能力维护

现行模型、Prompt、媒体、CAS 与 Embedding 通路已经存在。当前工作按 [结构收敛与 Wave Native](wave-native.md) 迁移其所有权和共享输入，而非重新执行一轮旧模型基建。

保持的产品能力：真实文本/结构化/流式生成、Prompt 编辑与预览、原件接纳和读取、图片/PDF/音视频准备、三种解释策略、部分结果、来源与向量空间绑定。

本轮迁移重点是共同应用操作、TaskDefinition、InputGroup 与 origin、确定性准备和明确语言阶段、受控批次物化及配置生效。接口和数据库可直接调整，真实消费者一起迁移。新语义输入不会恢复 retired SDK 或旧服务栈。

用户独立运行验证；不依赖 CI、测试数量或提供方 Mock 作为实际能力依据。模型接入仍经供应商中立网关，开发环境中的 New API 补丁独立保存。
