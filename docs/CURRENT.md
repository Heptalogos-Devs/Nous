# 当前工作

## 已有能力

本地实例、配置、启停、SQLite、CAS、多轴时间、执行和观测保持共同入口。表由组合根显式收集，正式内容的新增关系在实例边界采用；开发中临时改过内部结构的实验实例可在新目录重新初始化。实例可按可读 profile 登记和选择。

配置快照在创建时完成校验，`values` 提供深度不可变的类型化视图；普通操作复用同一快照。在线与离线配置修改进入共同执行边界。根操作绑定其 Runtime 的观测与实例关联，预先创建的异步 worker 同样保持外部 Trace 上下文。

模型和媒体共用输入规划与请求尝试策略。普通任务联合处理多份材料，独立模式按用户选择的语义单元执行。每次只准备实际选中的路线，备用路线在真正切换时才按同组原件和选区准备表示及所需转写；媒体分析各阶段也通过共同生成操作选择路线。媒体按真实类型协商表示，转换在消费当前批次时执行，保存实际 MIME、范围和来源。Prompt 预览、probe、生成与媒体各阶段消费同一套能力，纯预览不发语言请求。

SelectedInputs 保留原件、离散选区、slot、role 和已确认事实；实际交付的 SourceContext 随输入正式保存。无扩展名视频先探测类型，各阶段从同一选择规划；原生音频主路线不提前检查未使用的备用转写绑定。已保存描述可在新的结构化请求中显式引用。

Embedding 的 run、ensure、probe 和临时查询使用同一个批次执行器。已采用向量依空间、用途和精确输入选择规范行；网络不占用复用长锁，少量行读取通过 CAS 本地借用及 NPY mmap。临时查询默认不接纳新的正文或向量结果。

内容关系按输入组、part、origin 和输出规范化保存；显式来源槽和不连续选区贯穿实际采用的模型路线。共同阅读视图区分接纳类型与实际探测类型，沿所选材料和映射发现已有表示；结果分别回读原件选择、实际输入和命名产物，重开读取不要求模型配置。TextView 保留定义行、CRLF、空白和尾部，提供精确原文范围及按需结构。缓存读取、解析、绑定与序列化进入受管理线程；批量准备合并请求实际覆盖的范围，读取上限约束返回选区。

输出坐标映射由生产者与结果一起采用，后续读取沿正式映射迭代回溯。实际输入、所选材料、坐标映射和必要依赖分别保存；语义关联不伪造逐字节映射。

根操作保持稳定关联，子阶段和实际请求尝试可通过 JSONL 追踪。已保存但后续维护失败的 partial 贯穿结果、根终态、`runtime logs` 和 `runtime check`；后者也读取近期正文准备阶段摘要。默认不持久保存完整 Span 树。

日志出口按实例持有，根操作在当前 Task 绑定事件归属；预先存在的 worker 与跨实例嵌套保持正确关联，交错关闭不改变宿主日志配置。Note/Journal 编辑在启动编辑器前持有实际恢复文件，锁占用、冲突和未确认保存的出口保稿；`edit --resume` 使用原 expected 和维护请求，同一次已提交写入可重放。

Wave 使用 Rust retrieval 的 Engine、冻结快照、观测、CandidateSet、CalibratedPool、召回与读出。类型化 WaveProgram 编译端口和实际资源依赖，Native 共享数值输入；Python 组织可选模型评价与范围读取。PyO3 负责数组、detach 和对象边界。VCP 数值基准为 `d5c019e`，具名 DTSC 保留。稀疏图、长出现序列、多路径和明确支持组均有实际消费；查询可使用临时编码或已采用的显式 VectorRef。

局部词项与向量属于实际原文单元。统一 localizer 保留其尺度，TextView 提供句界和结构范围；程序在一次总预算内选择，随后读取正式原文。排名目录、评分范围、增量交付和共享上下文分别记录，局部 key 属于对应 EvidenceDelivery。

文稿投影、来源、候选向量和概念关系按实际输入共享。单篇计算资料与共享来源节点分别复用，组资格和快照上下文独立确定；仅改变标题或活动标注时复用未变正文布局，分别重组标题输入或标注图。构建完成后在一次事务中发布快照及其关系，并按捕获代次决定是否提升当前指针；查询借用和正式反馈引用保护资产，CLI 提供显式清理。标题进入独立词项字段与语义投影，排名依据和实际交付的精确原文片段分别表达。

默认 Namespace 可直接保存 Note 和 Journal。`open_instance` 持有一个 Runtime，CLI、SDK 和宿主通过同一 `runtime.app.call` 操作目录访问类型化请求。正文、精确来源与不可变版本支持读取、局部精确编辑、全文替换、差异、历史、归档和恢复；并发修改按基准版本检查。Note 默认不参与长期召回，可显式设为 remember。手写记录、修订和 lexical 查询无需模型。

NamespaceRef 持有稳定身份，改名或名称复用不会改变其归属。正文修改在共同 owner 分别核验 target 和 expected，跨对象前置条件拒绝执行。RevisionSelection 携带正式修订与精确选区，来源、草稿、查询和 current_basis 使用同一解析能力；活动标注按实际当前召回视图的变化推进 generation。

`journalize` 只形成新篇；局部自然语言修改建议、明确全文重写和跨篇反思各有独立任务。成功草稿固定输入、基准、来源和意见，可读差异后采用；重复采用返回原版本。正式 Concept 保留稳定身份及独立意义版本，正文标注固定块和 Concept 版本，提案采用后才进入当前认识。保存后可按配置接续标注，失败时保留已保存正文。

检索查询在一致读事务中捕获正式文稿、来源和已采用标注，按需通过 Wave 发布可重建快照；未变更时直接使用当前代次。明确引用的直接读取不构建快照。检索按文稿分组召回和交付，返回完整片段、精确版本、来源及类型化查询情境。查询反馈指向已保存交付及其片段键，并可独立处理或与正文修订同事务关联；显式 `current_basis` 的过期依赖显示待复核，历史引用保持可读。

共同材料通过显式登记提供领域 schema、稳定投影身份、资格、标注及来源事实；批量捕获使用同一读事务，正文结构在事务外准备。查询可使用自然语言、NousQL 或结构化表达式；any/all、软偏好与时间顺序由共同 Wave 操作执行，最后使用一份定位与交付预算。

Work 保存目标、焦点、有效决定、问题、进展、正式依据和实际使用，完整修订按 expected 检查。工作字段与明确活动材料按职责进入召回和定位情境，实际阶段、来源与贡献进入 QueryIntent。用户可跨进程读取 E、沿关系补读、修订决定并记录显式使用；查询反馈仍针对真实 E 交付。

普通 query 默认返回内存证据；`--save` 或随后 `save-evidence` 采用同一完成交付。Steward 可按用途读取已保存证据，形成独立 Markdown、结构化条目与正式材料来源；默认关闭。任务支持 native、tool 和 prompted，模型排序/评价保留原始尺度与实际用量。原文、阅读稿、草稿与正式修订各自有完成点。

HTTP、MCP 和 gRPC 由显式宿主按配置启动，与 SDK、CLI 和本地通道使用同一 Application。认证、请求期限、进度、取消与已提交引用保持共同语义；JSON Pointer 选择输出字段，完整结果 Schema 可发现。模型失败保留服务原因、状态、资源、接口、请求关联和实际等待信息。

AfterWrite 在正文提交后执行标注和刷新。等待模式直接返回各项结果；后台模式由允许后台工作的 Runtime 持有普通 Task，并返回本次运行期的操作引用。未启用后台能力时，显式后台请求在写入前拒绝；正文提交后未能启动维护时，结果保留正文并说明维护未启动。

完成的模型结果保存实际输入、输出和领域上下文，重开后无需模型配置即可读取。写作成果可重新组装为草稿；修改草稿创建新的完整草稿，正式采用核对精确基准并支持同一草稿的重复采用。未完成的调用在中断后由新的显式请求重新执行。

## 有效决定

保持供应商中立，真实模型访问统一网关。Python 拥有正式状态和业务采用，Rust 拥有可重建计算与索引。媒体、向量和 Wave 继续复用配置、Execution、事务、时间、内容与观测 owner。

普通查询在有向量空间时使用 Dense 与语义定位，无向量时使用 text_only 词项程序；默认整次原文预算为 2048 字符。原问题保留独立信号，工作情境按阶段参与。模型排序、评价与 Steward 由用途明确启用，默认直接交付精确原文；选择依据见[实验研究](research/composable-retrieval-study.md)。

血缘根集合不等于独立支持。关系通过 SupportGroup 区分共同前提与独立见证，解释性贡献通过显式 profile 启用，检索和标注不自动改变长期认识。

## 后续范围

任意历史知情视图和完整 Native 增量继续按领域与数学依赖推进。普通文稿增删改在可复用基代时增量更新词项和 ANN 索引；VCP 数值资产按实际依赖重建，精确旧修订和已保存原文独立可读。查询条件与已捕获锚定视图分别使用，未接领域选择器明确报告能力状态。

查询程序与局部交付见[程序合同](design/wave/program.md)和[定位合同](design/wave/localization.md)，使用入口见[认知命令](design/interfaces/cognition-cli.md)。Observation、Episode、Ego、Social、严格历史知情和情境性效用贡献见[后续认知发展](plans/cognitive-use-next.md)。
