# 当前工作

## 已有能力

Nous 已有本地实例、路径、配置解析与修改、启停、日志与遥测、进程内执行、SQLite 事务、多轴时间和本地管理入口。`nous tools` 支持 Prompt 管理、真实文字和结构化生成、流式输出、内容接纳与读取、图片/PDF/音视频准备和三种媒体解释策略。原件、派生物、结果及其来源可在关闭重开后读取；文本 Embedding 使用正式空间绑定并保存向量。旧服务栈不参与当前运行。

## 当前接入

本地网关已用于文字、结构化输出、图片、原生音频、有声视频和文本向量调用。当前网关未为所选模型提供可用的标准转写渠道（HTTP 503），已使用原生音频输入处理音轨；接入其他资源时按实际能力配置。FFmpeg 与 ffprobe 用于音视频准备。

## 有效决定

Python 主应用统一业务操作；成熟库承担网络、模型协议、模板、文件解析和数据库机制。实例和技术配置保持可解释、可修改。New API 是本次开发网关，产品保持协议与供应商中立。

验证围绕完整通路；不启用或依赖远端 CI。认知对象、Wave、DBOS、HTTP/MCP 与独立远程 SDK 在相应后续任务开展。
