# 当前工作

## 目标

建立可启动、可配置、可观察、可停止的 Nous 运行基础，为后续笔记、Journal、检索和模型任务提供统一能力。

## 当前决定

采用 Python 应用、SQLite、标准 asyncio、Pydantic 配置、logging / structlog 与 OpenTelemetry。路径按逻辑归属解析。首轮管理以本地 CLI 和进程内应用接口完成；完整远程管理和 MCP 在对应产品入口建设时接入同一操作。

启动配置可独立于数据库加载。危险修改按数据绑定语义处理。运行耗时、真实记录时间和认知时间域分别表示。Embedding 空间变化需要新空间与重建，禁止仅改同一已使用空间的模型或维度。

## 当前实现

本地运行基础按照 [运行基础实施计划](plans/runtime-foundation.md) 提供实例初始化、配置解析与修改、启停、日志和遥测、进程内执行、SQLite 事务与多轴时间。`nous runtime check` 实际打开并检查实例资源，然后正常关闭；它不要求模型或遥测后端。

内容存储、持久工作、模型执行、Wave、认知对象和 HTTP/MCP/远程 SDK 不在当前运行时中。模型、网络和 Embedding 仍可声明纯配置；Embedding 绑定负责人尚未接入，管理操作会拒绝无法检查的空间和关联模型身份修改。后续能力按独立计划接入。

旧服务、SDK、Native 代码和旧测试集中保存在 [legacy](../legacy/README.md)，当前包和检查只使用现行运行基础。
