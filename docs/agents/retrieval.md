# 源码和资料检索

代码检索服务于明确的问题：定位完整操作、所有权、实际消费者及变更影响。源代码以当前工作区为准。

- 使用已有的 CodeGraph 与 rg 查找符号、调用关系和跨包依赖；需要时使用可用的语义检索工具。
- 分析某项行为时，从真实入口沿类型和调用追到数据 owner，读实际实现与消费者。
- 先确认是否已有成熟库、运行时能力或项目实现，再决定新建模块。
- 文档按权威顺序使用：当前有效设计、当前源码与使用路径、研究资料、历史讨论。
- legacy/ 保存 Python/PyO3 旧系统，只能在明确要求研究具体历史算法或语义时定向读取；通常研发及代码检索排除该目录。
- docs/references/ 是早期产品思路与使用场景，供未来 Nous 产品设计时按需参考。文中涉及 Python、旧调用方式或旧数据模型的段落没有当前实施效力。

不得以旧代码函数名、旧测试或旧 Spec 推定新的基础设施必须保留相同结构。
