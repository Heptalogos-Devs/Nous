## 旧 Nous 与废案

master 的 `crates/persistence/src/mutations.rs` 已具有事务、请求摘要、操作回执和版本机制，使用 Postgres transaction 与 advisory lock。本批复制改编其 MutationEnvelope 提交结构到 `nous-storage`：SQLite 以 `BEGIN IMMEDIATE` 取得写入权，按调用者、操作、范围和 OperationId 查询完整回执；实例级 authority_state 分配 commit_seq。事务设施管理提交机制，应用操作管理业务范围。

读取 `crates/retrieval/src/mechanisms/lexical.rs`、`dense.rs`、`residual.rs` 及 `reference/fusion.rs`、`epa_training.rs`：已有 Tantivy/USearch 代际、EmbeddingSpace、残差迭代、向量融合与 EPA 训练代码。它们是后续算法比对和局部改编材料。

PR #56 的 `packages/platform/package.json` 及 `src/bootstrap/locations.ts` 显示了 TypeScript 公共平台、DBOS/Kysely/PostgreSQL、AI SDK、配置与目录处理。其逻辑路径集中解析有参考价值，但大量目录分别回落到平台默认位置，与本次临时内容集中 `temp` 的要求需要重新设计。新方案按 Rust 单体与实例根目录组织。

## 基础组件核实

`apalis-sqlite/src/sink.rs` 的 `push_tasks` 使用调用者传入的 SQLx Executor；`src/queries/mod.rs` 公开重导出该函数，`queries/task/sink.sql` 具有 `(job_type, idempotency_key)` 冲突处理。可以在领域事务连接上直接入队。`persist.rs` 提供持久状态与重投机制；领域幂等结果处理任务重投。

本批通过 apalis-sqlite 的嵌入迁移建立队列表，再使用 Nous 自己的连接设置。上游 `setup()` 会调整 synchronous；Nous 保持 WAL、FULL 同步、外键和 busy 超时。队列名 `nous.work.v1` 与 JobEnvelope 是版本化任务合同，持久任务独立于 Rust 类型名称。

`rust-genai/src/client/client_impl.rs` 已提供 `exec_chat`、`exec_chat_stream`、`embed`、`embed_batch`、`exec_embed`。Cargo 支持注入 Reqwest 客户端，可复用 Nous 网络配置。研究 HEAD 标记 0.7.1-WIP，正式实现先选择发布版本并检查所需 API。其多 provider 接入和嵌入值得直接使用，外部 rerank 的具体 provider 合同单独接入。

`rmcp/examples/servers/src/counter_streamhttp.rs` 已展示将官方 MCP service 挂到 Axum 并使用 CancellationToken 停止。直接复制改编例子，替换为 Nous 应用用例；HTTP 与 MCP 使用同一服务状态。

本批本地对象使用 tempfile：同文件系统暂存，写入与同步后 `persist_noclobber` 发布，随后校验长度和 SHA-256。材料原文具有内容摘要，Material 与每次 Observation 另有稳定身份。OpenDAL 随实际新增后端接入此边界。

SQLite WAL 允许读写并行、写入仍串行；部署数据库放本地磁盘。在线备份按官方一致性快照机制实施。参考 [WAL](https://www.sqlite.org/wal.html)、[Backup API](https://www.sqlite.org/backup.html)、[官方 MCP SDK](https://github.com/modelcontextprotocol/rust-sdk)、[rust-genai](https://github.com/jeremychone/rust-genai)。
