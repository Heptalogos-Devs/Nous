# 当前施工

## Objective

依据 `../../Specs/` 完整施工方案，从空数据与新的正式结构重建 Nous Wave 和 Heptalogos。完成独立及联合运行的认知、世界、自主性、任务、承诺、交往和产品管理；完成 OpenClaw 逐模型 prepare/accept 与 AstrBot 逐物理发送回执，保留原生工具、执行、历史和渠道。配置、权限、时间、费用与 trace 从第一条链进入代码。删除被替代的代码、协议、测试和文档，减少维护负担。

## Decisions

- 当前上游需求入口是施工方案包的 README、项目宪纲、架构、契约与施工顺序；按功能继续读取对应 Spec。
- 两个独立 TypeScript 模块化服务、两个 PostgreSQL 18 数据库。Kysely 保存业务事实，DBOS 5.3 保存工作流与事务检查点。
- `@nous-wave/contracts/common` 仅包含共同值；Zod 为公共输入输出来源。Hept 通过正式 Nous Client 使用认知。
- 材料存在、实际接触、形成认识分别采用；主观前台每主体串行；模型及外部效果在事务外执行。
- 新数据使用独立的新数据库，旧 Git 历史作为源码参考。
- 执行私有范围由受信消费者身份决定；选定成果通过 materials.publish 进入主体可读范围，来源政策始终沿依赖图生效。
- 网关价格不用于预算估计；当前真实联调保存实际 token/调用数，金额保持未知。
- 人类文档采用中文，AI 工作说明采用技术英文。
