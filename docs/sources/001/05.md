我看你这些启动、配置设计的也没问题。我认同。尤其是配置系统，它的机制更为复杂，而且在系统中举足轻重。配置的不同维度，字段的形态（类型、描述、缺失可否、范围等）都要花费精力梳理。

但是我们整个系统里面也会有些危险配置，通常强烈不建议修改，并且在首次配置时，就应当深思，比如 Embedding 模型的配置，模型选取、维度之类的。

基础服务确实还需要执行、时间、凭据、内容、本地化。尤其是时间我要额外提示，我们系统里有很多依赖时间的机制，比如某份材料何时入站、接触/观察、何时有效、被修改等等总之形成了我们设计过了的多轴时间体系。甚至未必与现实时间一致。
