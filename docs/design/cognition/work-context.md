# 持续工作

Work 保存一项持续工作的标题、目标、焦点、决定、问题、进展、阻碍、当前使用材料和关联对象。每项决定保留稳定 key、表述、有效状态及正式依据；问题保留状态与引用。附加说明使用 Markdown。

`WorkRef` 标识工作，`WorkRevisionRef` 固定不可变修订。创建和修订先准备正文与确定性字段表示，在一个短事务内提交状态、正文、字段范围和材料引用。修改要求精确基准或 expected；基准不是当前修订时返回冲突。所有已保存修订可独立读取。

`work.set_active` 使用同一修订机制替换当前材料集合。`work.record_use` 接收精确工作修订、已保存证据、实际使用选区、用途及可选阅读稿和决定 key；选区可以来自证据或其后续补读的正式材料，由共同材料接口校验。`work.list_uses` 按最近使用读取正式关系。

工作状态经共同材料接口读取，字段的确定性 Markdown 表示保留各字段的字节范围。`cognition.search.include_work` 开启时，当前工作修订参与对应 Namespace 的检索捕获；状态变更推进该视图的内容代次。引用原材料和正式使用关系保留精确对象，不复制整份候选列表。

查询显式指定工作修订后，可采用目标、焦点、有效决定、未决问题、当前材料与最近实际使用内容。第二个会话可以读取同一 Work、查证原文、修订决定并记录新的使用关系；运行期任务状态随宿主结束，而 Work 修订和成果继续可读。

命令及 JSON 输入示例见[认知命令](../interfaces/cognition-cli.md)。
