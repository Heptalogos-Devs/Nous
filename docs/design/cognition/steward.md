# 有来源的阅读整理

`steward.arrange` 读取已经保存的 EvidenceDelivery，按用途、粒度和可选语言生成 ReadingBrief。整理输入包括用户提出的问题、关注方面、实际绑定的选择和时间条件，以及实际使用的情境。每个结论、条件、分歧或背景条目引用本次交付的证据键；待探索的问题可以不带引用。提示词要求保留影响结论的条件、否定和分歧。

阅读稿与原始证据是独立结果。证据先保存，整理后的结构化条目和 Markdown 再作为新的 ProcessingResult 采用，结果依赖原证据；Markdown 各条目的映射指向实际引用选区。失败或取消时已保存证据仍可读取，之后可独立重新整理。查询可选择关闭、可选或要求整理。

整理时模型可对已交付的 E 键请求前一段或后一段原文。系统至多扩展一次，在同一材料中确定邻文，用原交付的预算和计量方式对实际范围去重计费。扩展成功后保存新的证据交付，阅读稿依赖该交付；预算不足或邻文不可用时保留原交付和已有阅读内容，并报告未完成的扩展。后续查询和补读仍由使用者决定。

配置生成任务 `arrange-reading` 和同名提示词后使用。任务可采用模型原生结构化、工具调用或文本提示结构化策略；结果均经过阅读合同校验。具体入口与其他模型任务使用同一连接、期限、重试和用量记录。
