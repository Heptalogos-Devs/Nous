# 有来源的阅读整理

`steward.arrange` 接收已保存的证据成果，或直接接收正式材料引用和精确选区；按用途、粒度和可选语言生成 ReadingBrief。直接输入由材料 owner 解析并分配本次 E 键。整理已保存证据时，调用方提供的问题、方面和情境优先生效；未提供的内容沿用保存的查询情境。查询直接发起整理时，将本次已选来源和情境交给同一整理操作。每个结论、条件、分歧或背景条目引用本次交付的证据键；待探索的问题可以不带引用。提示词要求保留影响结论的条件、否定和分歧。

阅读稿包含结构化条目和 Markdown，作为 ProcessingResult 保存；使用已有证据时，结果依赖该证据；Markdown 各条目的映射指向实际引用选区。失败或取消时已保存证据仍可读取，之后可独立重新整理。查询可选择关闭、可选或要求整理。

一次整理使用已经选择的材料并调用一次模型。需要更多上下文时，可继续读取正式材料，再选择材料进行新的整理。

配置生成任务 `arrange-reading` 和同名提示词后使用。任务可采用模型原生结构化、工具调用或文本提示结构化策略；结果均经过阅读合同校验。具体入口与其他模型任务使用同一连接、期限、重试和用量记录。
