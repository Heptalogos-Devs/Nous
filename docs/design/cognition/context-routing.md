# 查询情境路由

原问题保留独立查询信号。`ContextSelection` 可指定精确工作修订、显式片段和先前证据；`QueryAnchor` 还可提供精确材料选区，并选择当前视图或先前快照。领域提供已采用对象和实际引用，认知查询准备选择参与当前阶段的情境。

工作目标、焦点、有效决定及未决问题具有各自字段范围；当前材料和最近实际使用内容以原材料精确选区进入情境。当前决定按有效状态选择。活跃使用按配置窗口选择，可配置使用序列距离的半衰期；无半衰期时保留有效贡献。

工作目标、焦点、有效决定和明确活动依据默认参与召回与正文定位。未决问题、历史使用、先前交付及锚定选区默认参与召回。SDK 可以用 `ContextSelection(stages=("retrieval", "localization"), ...)` 指定这些自动情境参与的阶段；CLI 可重复使用 `--context-stage`。直接提供的 `ContextFragment` 使用自身声明的阶段。实际选择及各阶段贡献记录在结果的 `QueryIntent`。

每个 `ContextFragment` 指明角色、阶段、父材料、来源、权重、相关性、有效性、距离与可选半衰期。Wave 负责以真实父单元计算质量，在同一角色和阶段为无效情境保留 null mass，再将父质量分配给实际片段。原问题单独参与召回；已选上下文及其实际贡献回传并写入 `QueryIntent`。

语义与词项路径、候选合并、排序以及最终原文定位由所选 Wave 程序执行。排序和交付分别消费其所需情境；同一份材料的重复切分不会因片段数量增加父贡献。参数和具体程序见 [Wave 查询情境](../wave/query-context.md)与[程序](../wave/program.md)。
