# 备用路线与阶段内尝试

## 路线定义

任务保存有序的主模型与 fallback。每个 fallback 缺少 preset 时继承该任务 preset；明确提供 preset 时替换。候选按同一 ConfigSnapshot 解析，模型名作为数据传递。

每条路线独立计算支持的参数、输出额度、上下文与协议能力。主模型的输出长度、时限和窗口不会因为一个较小备用模型而提前取全链最小值。阶段总期限和调用次数由任务/实例共同约束。

## 能力兼容

固定的是请求含义、原件及实际选区、任务标准和输出合同。可复用同一确定性表示时直接使用；需要另一确定性表示时必须保留同一原件与完整选区，并在实际请求中写明。新增转写、描述等语言阶段只由 MediaAnalysis 明确组织，不能在 fallback 中自动新增。

在准备时为每条路线记录 eligible 或具体不适配原因。不适配路线不发请求，也不降低主路线能力。全部不可用时返回具体缺项。媒体丢音轨、PDF 截页、摘要替原文均不属于兼容变换。

## 次数、错误与流

一次语义阶段的主请求、重试、结构修复与备用请求共用 max_attempts；描述和结构化属于两个计划内阶段，各有计数，但继承根 deadline。按候选顺序尝试，最后候选可在剩余次数内重试。使用实际 retry-after 但不越过期限。

结构修复复用已选路线，除非其请求发生可重试服务错误才切换备用。Pydantic AI Direct API 负责反馈的协议投影。输出校验错误不默认触发第二模型同意流程。

流开始后不拼接另一模型；取消不重试；保存失败不重跑模型。每次真实提交及已知用量归同一阶段结果，不依赖 SDK 隐式计数。
