# 凭据引用与解析

## 责任

Credentials 解析本实例配置明确引用的凭据，供网络和模型连接使用。支持 env 与 file 两种现有可判别配置，返回仅供连接使用的秘密值。解析不创建账号、修改网关渠道或管理外部服务。

file 引用的相对路径以实例配置目录为根；env 引用精确环境键。凭据值缺失返回具体引用和缺失原因。普通配置、模型列表、Prompt 预览不要求先连网验证。

## 开发接入

用户的本地 Docker New API 已被授权用于本轮真实调用。Coding Agent 主动读取现有部署与可用调用凭据；需要通过网关已授权管理入口生成/取得本项目调用 Key 时直接完成。具体定位见 [本地网关](../../development/local-gateway.md)。

运行时配置只保存通用引用。开发实例的实际值保存在仓库忽略的本地文件或现有环境，交付文档只保留引用名。无需另建密钥保险库、权限申请或费用确认流程。

## 生命周期

连接构造时解析凭据；本轮 Provider endpoint/protocol/credential_ref 改动按重启采用。已有请求使用已取得连接，不在流中途重新读取环境。后续确有轮换需求再在连接 owner 中增加实际能力。

SDK 可以获得真实密钥；Prompt、模型输出、用户 JSON 结果和 Trace 不需要该值。通过现有 SecretStr/日志过滤处理，禁止为此自研泛化秘密扫描框架。
