# 音频表示与转写阶段

WAV/MP3 等由 FFmpeg/ffprobe 探测和按已选时段转换，确定性产物通过 CAS 与 ResultStore 保存。准备器负责字节、采样率、声道和时段；它不“理解”声音。

当本次模型接受原生音频时，语言阶段发送真实音频 part。当明确选择转写路径时，由 MediaAnalysis 调用 GenerationOperations.transcribe，通过共同 ModelExecutor 的标准转写端点执行并采用结果。目标模型不能读音频而未配置转写时，返回具体缺项，不在 prepare/preview 中临时找模型。

转写属于独立语言产物，有自己的任务、模型、实际输入和用量。转写后做结构化时，明确标记输入表示为 transcript；它不能冒充原生听到了情绪、音乐或其它非语言声音。描述与结构化任务仍根据实际提供的音频/转写表示工作。

选区 origin 相对原音频起点，分片的本地时间单独表示；同一时间范围可有多个声道/表示，输入顺序和来源不丢失。成功分片可以显式复用；失败返回已完成引用和剩余范围。该能力与开发环境的网关修补无生产依赖。
