# 图片与动态图准备

## 静态图像

使用 Pillow 读取真实尺寸、格式、EXIF 方向和色彩模式。原件保持原字节；模型不接受原格式或需要缩放时，产生规范化派生图。实际旋转、缩放与格式写入 producer，选区坐标通过明确变换关联原件。

默认使用配置的 max_side 对过大的模型输入做等比例处理；原始图片仍可精确读取。透明图转 JPEG 时必须明确背景，优先保留为支持的 PNG/WebP。不要仅为了格式整齐反复重编码已经可用的输入。

## GIF 与动画

GIF 包含多帧及帧间时长。media inspect 返回实际帧数、总时长和尺寸；分析按时间采样并保留帧/时间位置。第一帧不能代表整段动画。帧上限用于批次，完整请求的采样结果全部参与对应批次。

没有动画理解要求的使用者可以显式选择某帧；结果覆盖只声明该帧。

## 模型输入

原生支持图像的生成任务使用实际二进制，description、structured 和两阶段策略共用同一准备结果。第二阶段读取原图或本次实际采用的精确派生图及描述；不能仅剩一个无法解析的文件名。

可读结果注明来自原图或转换图。确定性图像处理结果按输入/选区/参数/工具版本复用。

依据：[Pillow Image](https://pillow.readthedocs.io/en/stable/reference/Image.html)、[Pydantic AI 多模态输入](https://pydantic.dev/docs/ai/core-concepts/input/)。
