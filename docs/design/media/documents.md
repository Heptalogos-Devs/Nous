# PDF 内容准备

PDF 文本与页图使用 pypdfium2/PDFium。页码对外从 1 开始；选页含端点，输入范围外报错。页文本与 PNG 输出均以具名 Artifact 保存，InputGroup 分别指向二者及其 PDF 原页。

## 表示选择

auto 优先使用当前路线真实支持的原生 PDF；整份超过一次请求上限时使用已声明页范围分批的子 PDF 或视觉表示。visual 使用页图及可提取文字。text 只使用可提取文字；无文本页明确需要视觉处理，不自动构建 OCR 平台。

原生 PDF 子文件与原页建立 origins，不能将子文件页 1 误写成原件第 1 页。

## 缓存和并发

保留 fdb39e4 的已保存页先查缓存、只渲染缺页行为。缓存键包含原件、页、模式、分辨率和工具版本。同一转换键由一个实际转换负责者执行；别的请求等待或使用已提交结果，分别保存自己请求的覆盖。

PDFium 不允许并发访问时的进程级 threading.Lock 位于 worker 内，完整包住打开/解析/关闭。异步等待取消不会提前释放锁或原文件。批量为一个有限页组，不为了缓存预读整本并保持所有页图在内存。

使用已有成熟解析器，不重写 PDF 页面、编码或字体逻辑；预览和模型执行使用同一准备能力。
