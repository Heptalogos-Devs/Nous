# 共同认知材料

`MaterialRef` 固定文稿修订、接纳的原件、处理结果的命名输出或 Work 修订。共同材料读取按引用类型调用对应领域，完整正文、身份、状态和关系由各自 owner 保管。

`materials.read` 接收精确引用、`MaterialSelection` 或已保存交付加证据键。返回 `CognitiveMaterialView`、选定的内容视图及其来源；`materials.follow` 沿指定关系读取正式引用。可读短引用由相应 owner 解析，结果命名输出可写作 `结果引用:输出名`。结果只有一个主输出或包含 `evidence` 输出时，结果引用可直接选中该输出。交付内的局部键必须与交付引用一起使用。

文稿视图保留精确修订、正文、来源、时间和召回状态；结果输出保留实际输入、形成背景、输出关系与所选范围；原件保留接纳身份及现有表示；Work 的状态属于 Work owner。Markdown 块的范围指向不可变原始字节。属性由领域的静态 Schema 定义并可通过材料接口发现。

文稿修订按来源键保存实际采用的材料身份，选区、角色和显示名仍由该修订的来源绑定负责。正文和选区相同但材料身份改变时形成新修订；后续编辑保留未移除来源的精确身份。写作来源可直接指定 Work 修订、材料选区或结果命名输出，读取时使用该修订保存的关系。

各领域提供当前材料和精确引用的批量捕获。`MaterialSnapshot` 在调用方同一读取事务中固定材料事实、正文引用和内容摘要；其索引事实声明稳定材料键、可检索资格、标注、支持关系及独立来源。文稿捕获包含来源、当前活动标注、复核状态与原始首版，Work 保留其领域状态和字段范围。捕获不解析正文，事务结束后按需要批量读取内容并准备结构。检索按共同索引事实选择资格和建立投影。

模型任务解释器返回 `InterpretedOutputs`：命名产物、各产物映射和有名精确选区。一般任务声明实际输入的派生关系；选段任务直接给出选中的内容。ResultStore 校验映射、保存选区并原子采用成果，内容读取从采用时登记的关系查找已有表示。模型实际输入、用户所选材料和程序组装输入分别记录。

结果及修订采用结果输出作为正式来源时，引用关系受数据库外键保护。显式删除没有被使用的结果时，同一事务移除该结果的关系并释放其持有的快照；已有其他使用者时拒绝删除，原件及输出 Artifact 保留。

已完成的描述输出可以作为新任务的上下文：新问题和指令独立指定，描述自己的原始范围与形成事实仍由原结果保存，当前任务按其实际需要重新准备原件。
