# 共同认知材料

`MaterialRef` 固定文稿修订、接纳的原件、处理结果的命名输出或 Work 修订。共同材料读取按引用类型调用对应领域，完整正文、身份、状态和关系由各自 owner 保管。

`materials.read` 接收精确引用、`MaterialSelection` 或已保存交付加证据键。返回 `CognitiveMaterialView`、选定的内容视图及其来源；`structure=true` 时提供章节目录，`blocks` 可按块键读取，默认不生成章节。`materials.follow` 沿指定关系读取正式引用。可读短引用由相应 owner 解析，结果命名输出可写作 `结果引用:输出名`。结果只有一个主输出或包含 `evidence` 输出时，结果引用可直接选中该输出。交付内的局部键必须与交付引用一起使用。

材料视图提供精确身份、正文、媒体类型、来源、时间及正文结构。文稿和 Work 的详细状态由各自 owner 提供，成果的实际输入、形成背景与输出映射由 ResultStore 提供。Markdown 块的范围指向不可变原始字节。

文稿修订按来源键保存实际采用的材料身份、选区、角色和显示名。正文和选区相同但材料身份改变时形成新修订；后续编辑保留未移除来源的精确身份。写作来源可直接指定 Work 修订、材料选区或结果命名输出，读取时使用该修订保存的关系。

各领域提供当前材料和精确引用的批量捕获。普通阅读只取得材料事实、正文和来源；检索在同一读取事务中另向文稿、Work、标注及内容 owner 取得召回资格、标注、独立来源和内容摘要，再建立索引事实。正文解析与读取在事务结束后按需进行。

模型任务解释器返回 `InterpretedOutputs`：命名产物、各产物映射和有名精确选区。一般任务声明实际输入的派生关系；选段任务直接给出选中的内容。ResultStore 在一次采用中保存所选材料、实际输入、转换来源、命名选区和输出映射各自的关系。不同输出可引用不同正式来源；读取只展开所请求输出的来源。

结果及修订采用结果输出作为正式来源时，引用关系受数据库外键保护。显式删除没有被使用的结果时，同一事务移除该结果的关系并释放其持有的快照；已有其他使用者时拒绝删除，原件及输出 Artifact 保留。

已完成的描述输出可以作为新任务的上下文：新问题和指令独立指定，描述自己的原始范围与形成事实仍由原结果保存，当前任务按其实际需要重新准备原件。
