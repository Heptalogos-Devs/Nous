# 多轴时间视图与时间关系计算

## 本轮状态

本专题确定目标设计和可计算规则。本轮实现仍以显式来源子集构建快照，实验使用这条现有通路；不实现完整 Journal 历史存储、任意 $asof 或时间扩展传播。未来实现使用本合同，无需从讨论重新猜语义。

## 查询含义先确定

| 意图 | 决定可用内容的规则 |
|---|---|
| 某日发生的事 | occurred 与事件关系 |
| 主体当时已经接触的内容 | subject/observer + observed，并检查后续理解的 formed |
| 系统当时保存了什么 | recorded 截面及实际版本 |
| 某段时间什么仍有效 | valid |
| 今天回顾过去 | 当前可知内容 + 指定 occurred 范围 |
| 最近值得关注 | 明确时间轴、时间域、参考坐标和软偏好 |

允许组合，但多个条件必须落在同一个实际声明/来源组。叙述顺序、经历时间、Sense hop 各自独立。外部补录可以拥有旧 observed、旧 occurred 和今天 recorded，不能回填 recorded 假造历史。

当前认知检索采用正式文稿修订的 `recorded` 时间；普通 Artifact 的 `recorded` 由内容 owner 登记，手工集合声明不能覆盖它。查询时保留候选及其来源组各自的时间，不把正文 Artifact 的登记时刻替换成文稿修订的记录时刻。

## 严格视图

严格历史/访问范围先决定正文修订、Concept 意义版本、关系贡献与支持组，再构建几何、传输图和索引。仅过滤最终 hits 会留下未来/范围外资产对几何与传播的影响。

```text
select_view(subject?, axes, evidence_scope)
  -> frozen body/concept/relation revisions
  -> build/reuse numerical snapshot
  -> query/readout
```

联合支持组只有所有 required roots 都在该视图可用时才完整参与。先删除不合法贡献再执行传输校准；不能在已经校准的全图上减几条边就声称得到完整历史视图。现有 `authorized_view` 一类衰减投影若没有符合其含义的真实消费者，删除；它不能承担严格历史/权限职责。

虚拟/模拟时间需要明确域与参考坐标。不可映射域不比较时间差。未知/不确定时刻沿用 TemporalValue，不补午夜、当前 UTC 或假精度。相关时间选择使用共同 TimeService。

## 可研究的时间门控

在已经合格的视图中，若查询需要偏向某一时间关系，可以对非负行传输矩阵增加门控：

\[
P^q_{ij}=P^{view}_{ij}g_q(i,j),\qquad 0\le g_q(i,j)\le1.
\]

P 的行表示 source→target，列向量的场为：

\[
u=(1-\alpha)s+\alpha(P^q)^T u.
\]

若原行出流和上界为 \(\rho<1\)，则门控后仍有 \(\| (P^q)^T\|_1\le\rho\)，固定点映射的压缩率至多 \(\alpha\rho<1\)。因此在该约束下有唯一固定点。被削弱的质量不自动重新分配；否则会把过期边的份额转给其它关系。

同一个 P^q 必须供 Sense、双场、真实边检查与读出使用，不能传播走全图、最后评分才声称时间受限。门控是后续实验 profile；它不自动决定因果，也不改变上游默认公式。

## 历史与新鲜度分别设计

软新鲜度可以基于明确轴的时间差设 \(r=2^{-\Delta/h}\)，h 为同域半衰期。先形成一个独立时间排序通道，再用已有 rank fusion 作显式最终偏好；保持原 quality_score 与 RiverMemo ranking_score 的解释，不把二者混成新的真实性分。

长期技术知识缺省不因年代降权；事件/安排可以按用途选轴。未来事件、开放区间、未知时刻分别处理；没有可靠差值时标 unknown 并保留可解释政策。

真实事件路径若需要时间单调，应携带“上一事件时间/区间”与下一事件约束；Sense 的 hop 仅是计算深度。本轮不把该状态偷偷塞进已有传播后宣称支持时间推理。

## 首次落实的位置

Journal owner 提供版本/知情/适用视图；Social/Episode 提供各自关系时间；Wave 消费合法资产。共同 TimeService 只解释时间值与域，不能决定一个人格或关系是否成立。DBOS 在后续需要恢复构建时调度相同操作，不参与时间语义。
