# Nous

Nous 正在重新建设。**当前只开发通用基础平台，并以独立发布、独立使用及非 Nous 项目的真实体验作为第一阶段终点。** 平台完成后暂停，不自动继续认知系统业务实现。

技术栈：Bun 1.4.4 / TypeScript 7.0.2 / Zod 4.6.7 / Rust 1.100.0 / napi-rs 3.x。平台实现尚未落地；这里暂时没有可执行的新 Nous CLI，也没有可运行的原生扩展。
